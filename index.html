How QueueLens works

  1. Export tickets as CSV from Zendesk, Freshdesk, Jira Service Management, Help Scout or any helpdesk.
  2. Open QueueLens and select the file; confirm the suggested column mapping.
  3. Set response and resolution targets per priority.
  4. Review SLA status, backlog aging, workload and data quality, then export a filtered CSV or print the report.

Privacy: your ticket data is processed locally in your browser. QueueLens does not upload your CSV files to an application server or store your ticket records in a cloud database, and it uses no analytics or tracking.

Frequently asked questions

What is QueueLens?

A free, browser-based tool that analyzes support-ticket CSV exports and reports SLA estimates, backlog aging and agent workload.

Is my ticket data uploaded to a server?

No. There is no backend; the CSV stays in browser memory and is released when you clear data or close the tab.

Which helpdesk exports are supported?

Any CSV export. Columns are auto-suggested and can be mapped manually, so Zendesk, Freshdesk, Jira Service Management and Help Scout exports work.

How is SLA calculated?

Response = first response − created; resolution = resolved − created, both in calendar hours, compared to your priority targets. Open tickets use the current time. Statuses: Met, Breached, On track, Overdue, Not measurable, Needs review.

How is backlog aging classified?

Unresolved tickets: Fresh 0–24 h, Aging 24–48 h, At risk 48–72 h, Critical 72+ h.

Is it free?

Yes. No account, no cost, hosted on GitHub Pages.
