# QueueLens
Free, private, browser-based support-ticket analyzer: SLA estimates, backlog aging, agent workload. No backend, no tracking, no upload.
Live: https://manayab.github.io/Queue-Lens/

Zero-build static site (HTML/CSS/vanilla JS). Run locally: `python -m http.server` then open http://localhost:8000.
Deploy: push to `main`; Settings → Pages → Source: **GitHub Actions**.
SLA figures are calendar-hour estimates, not official helpdesk SLA values.
